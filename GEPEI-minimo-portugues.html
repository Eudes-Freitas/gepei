Modelo em português com relacionamentos e cardinalidades

A cardinalidade 1:N significa que um registro da primeira tabela pode se relacionar com vários registros da segunda. Os campos em azul são chaves primárias; os campos em laranja são referências.

Tabelas

usuario

  • id
  • nome_usuario, senha, nome, sobrenome
  • email, ativo, ultimo_acesso, criado_em
  • grupo_id

grupo

  • id
  • nome

permissao

  • id
  • codigo, nome
  • grupo_id, tipo_conteudo_id

tipo_conteudo

  • id
  • aplicativo, modelo

organizacao

  • id
  • nome, sigla, ativo

unidade_organizacional

  • id
  • nome, sigla, tipo_unidade
  • organizacao_id

perfil_usuario

  • id
  • usuario_id, unidade_id

plano

  • id
  • nome, sigla, tipo_plano
  • inicio, fim, ativo

item_plano

  • id
  • tipo_item, codigo, titulo, descricao
  • item_pai_id, plano_id
  • situacao, progresso, prazo, valor_alvo

plano_acao

  • id
  • acao_id, gestor_id
  • criado_em

atividade

  • id
  • titulo, descricao, ordem, peso, progresso
  • plano_acao_id, executor_id
  • inicio, fim, custos e recursos

registro_atividade

  • id
  • atividade_id, criado_por_id
  • tipo_registro, situacao, descricao
  • bloqueio, resolução e evidência

indicador

  • id
  • codigo, nome, formula, unidade_medida
  • periodicidade, direcao, linha_base
  • unidade_responsavel_id

medicao_indicador

  • id
  • indicador_id, registrado_por_id
  • periodo_referencia, valor_medido, valor_esperado
  • datas, fonte e evidência

vinculo_indicador

  • id
  • indicador_id, item_plano_id, unidade_organizacional_id
  • tipo_vinculo

risco

  • id
  • titulo, causa, probabilidade, impacto, situacao
  • atividade_id, acao_id, responsavel_id
  • tratamento e medidas

evento_risco

  • id
  • risco_id
  • tipo_evento, avaliação, tratamento, aceite
  • materialização, remediação e evidências

ciclo_relatorio

  • id
  • plano_id, criado_por_id
  • nome, inicio_periodo, fim_periodo, situacao

relatorio

  • id
  • ciclo_id, plano_id, unidade_id, validador_id
  • tipo_relatorio, situacao, resumos, fotografia
  • ano, trimestre e consolidação

registro_auditoria

  • id
  • usuario_id
  • entidade, campo, valores, acao, justificativa

notificacao

  • id
  • destinatario_id
  • tipo, mensagem, canal, situacao
  • emissão, leitura e envio

vinculo_plano

  • id
  • item_origem_id, item_destino_id, criado_por_id
  • tipo_vinculo, natureza, validade, percentual

registro_administrativo

  • id
  • tipo_conteudo_id, usuario_id
  • objeto_id, descricao, tipo_acao, realizado_em

migracao / sessao

  • infraestrutura do sistema
  • migracao: id, aplicativo, nome, aplicada_em
  • sessao: chave, dados, expira_em
